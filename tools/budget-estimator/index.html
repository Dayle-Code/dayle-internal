Herramienta interna

Estimador de presupuestos por proyecto

Guía interna para estimar proyectos por fases, módulos, horas, riesgo y perfil de cliente. Está pensada para Dayle hoy: emprendedor-friendly por defecto, pero capaz de analizar sistemas internos, automatizaciones, backends, dashboards e ideas todavía inciertas.

Uso recomendado Entrada + fases

Primero obtené una base. Después decidí si se vende completo, como MVP o como relevamiento pago.

No usar como precio automático. El resultado sirve como base interna. Para proyectos grandes, no lo uses como precio cerrado: convertí el número en fases, MVP, relevamiento pago y mantenimiento mensual.

Paso 1

Base del proyecto

Elegí el tipo de proyecto y el modo comercial. El modo no cambia la realidad técnica: cambia cómo conviene venderla.

Paso 2

Tamaño del alcance

Estos valores escalan el cálculo. No busques precisión falsa: usalos para no subestimar tamaño, datos, roles e integraciones.

Páginas vs pantallas

Página es algo público tipo landing. Pantalla es una vista de app: login, listado, detalle, editor, dashboard, etc.

Entidad de datos

Algo que el sistema guarda o administra: producto, pedido, cliente, usuario, turno, factura, tarea, movimiento.

Integración o automatización

Integración conecta con otro servicio. Automatización ejecuta un flujo: avisar, sincronizar, calcular, generar o enviar.

Paso 3

Factores de riesgo y criterio comercial

No todo se cobra por cantidad de pantallas. Un proyecto urgente, ambiguo o nuevo para el equipo necesita más cuidado.

Regla práctica

Si dudás entre dos opciones, elegí la más baja y anotá la duda como pregunta. No infles por miedo.

Alcance abierto

Cuando el alcance está verde, la respuesta comercial no es subir mucho el precio: es proponer una fase corta de definición.

Paso 4

Módulos del proyecto

Activá solo lo que entra en esta fase. Para sistemas grandes, presupuestá el primer módulo útil, no todo el universo.

Paso 5

Márgenes, buffer y costos externos

Esta sección no es “cobrar por cobrar”. Cubre coordinación, pruebas, imprevistos y ganancia real. En modo emprendedor va más liviana.
