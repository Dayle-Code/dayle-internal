## Nota de formato

Los documentos internos dentro de `docs/` deben conservar esta estructura inicial:

```md
---
layout: default
title: Título del documento
description: Descripción corta del documento.
---

# Título del documento
```

De esa forma, GitHub Pages genera automáticamente:

```txt
/docs/PROJECT_PARTICIPATION_POLICY.html
```
