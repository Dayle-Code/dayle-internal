# Plantillas de GitHub

Este documento explica cómo usar las plantillas internas de GitHub dentro de Dayle Code.

## Pull Request

Archivo fuente:

`.github/PULL_REQUEST_TEMPLATE.md`

Usar para describir cambios, pruebas realizadas, riesgos y notas relevantes antes de mergear.

## Bug report

Archivo fuente:

`.github/ISSUE_TEMPLATE/bug_report.md`

Usar cuando algo no funciona como debería.

## Feature request

Archivo fuente:

`.github/ISSUE_TEMPLATE/feature_request.md`

Usar para proponer mejoras, registrar pedidos de cliente o definir cambios de alcance.
